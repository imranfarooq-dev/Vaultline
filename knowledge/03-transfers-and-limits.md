# Transfers, Payments and Limits

## Daily withdrawal limits
Every account has a daily withdrawal limit. Withdrawals and outgoing transfers (including fees) count towards it. The limit resets at midnight. If a transaction would exceed the limit it is rejected with the message "Daily withdrawal limit exceeded".

## RAAST (domestic instant payments)
- Only Pakistani Rupees (PKR) are supported.
- The beneficiary must have a valid 24-character Pakistani IBAN, for example PK36SCBL0000001123456702.
- Maximum Rs 1,000,000 per RAAST payment.

## SWIFT (international wires)
- A valid BIC/SWIFT code for the beneficiary bank is required, for example DEUTDEFF.
- A purpose of payment is mandatory, such as "Family support" or "Tuition fee".
- Fee: Rs 2,500 plus 0.1% of the amount.
